Privacy Policy

Effective Date: June 2026

🔒 Zero-Server Architecture: This application does not collect, harvest, or store your data on any external database. All information is completely ephemeral.

This Privacy Policy governs the use of the Interview Code Share application ("the Application") within Microsoft Teams. We are committed to maintaining strict data privacy standards.

1. Data Collection and Storage

The Application is fully client-side and serverless. We do not operate any backend database or storage servers:

  • No Code Persistence: The source code written during your technical interview sessions is stored purely in the volatile memory of your local web browser. It vanishes completely when the session ends or the tab is closed.
  • No Personal Information: We do not collect, request, or parse your name, email address, password, or any other personally identifiable information (PII).

2. Peer-to-Peer Data Streaming

All collaborative features (including keystroke synchronization and language selection) are transmitted directly between the interviewer and the candidate using the WebRTC (Web Real-Time Communication) protocol.

  • Data packets flow directly from browser to browser.
  • An un-logged, out-of-band public signaling utility is utilized exclusively to establish the initial network handshake connection. No application data passes through or is kept by this discovery broker.

3. Cookies and Local Storage

The Application may utilize localized browser configuration parameters (such as caching your preferred language framework or layout theme preferences). No third-party marketing or tracking cookies are ever deployed.

4. Changes to This Policy

As a serverless utility, this framework's data-handling operations will remain zero-retention. Any structural updates to this privacy sheet will be deployed directly onto our public application platform registry path.

5. Contact Us

If you have questions regarding this serverless framework, please open a formal inquiry ticket via our public source code repository profile page.
