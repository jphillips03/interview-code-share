📋 Interview Pre-Flight Checklist

  • ✔️ No data is saved on external servers (Fully P2P).
  • ✔️ Monaco Editor (VS Code engine) will load automatically.
  • ✔️ A fallback link will be ready if your candidate is an external guest.
  • You will see '⚡ Waiting for Peer Connection...' in the top right corner of the screen until anyone else connects to the room.
  • Once a connection is made successfully you will see '🟢 Peer Connected (Direct P2P)'

🌐 Enterprise ICE/TURN Server Configuration (optional)

Credentials for open relay metered servers are optional below (free account options available here); A direct UDP connection is attempted using a STUN server, but a TURN server may be used as a fallback to handle streaming connection data between peers. If utilized the TURN server routes packets securely through pre-encrypted DTLS-SRTP protocols, it cannot decrypt or view any data exchanged between peers.
